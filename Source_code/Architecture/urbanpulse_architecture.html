⑤ Serving Layer

Dashboards · Advisory APIs · Signal Control Interface

End-user & system consumers
📡
Operations Dashboard
City Control Room staff
Grafana-based real-time dashboard. Live AQI heatmap by zone, smart-meter voltage sparklines, bus position map, junction wait-time gauge. Auto-refreshes every 10 s.
GET /api/v1/aqi/live?zone=Central WS /ws/bus-positions GET /api/v1/meters/ward/{ward_id}
🚨
Advisory API
Public apps · Emergency services
RESTful alert gateway. Broadcasts AQI threshold crossings (>150) within 2 min. Webhooks to mobile apps, external health authority systems, and emergency SMS gateway.
POST /webhooks/aqi-alert GET /api/v1/alerts/active GET /api/v1/forecast/aqi?zone=North
🚦
Signal Control Interface
Traffic Management System (TMS)
Adaptive signal controller command bus. Flink pushes phase-change commands to junction actuators via MQTT. TMS operators can override via REST. Response within 90 s of congestion trigger.
MQTT urbanpulse/signals/{junc}/cmd PUT /api/v1/signals/{junc_id}/override GET /api/v1/signals/status
📊
Councillor Report Portal
Elected councillors · Ward offices
Self-service web portal backed by Apache Druid. Weekly PDF generation, trend charts, ward comparisons. Exportable Excel. SSO login via city identity provider.
GET /reports/weekly/{ward_id} GET /reports/monthly/state-submission GET /druid/v2/sql (OLAP queries)
🗺️
Transit Passenger App API
Citizens · Mobile apps
Public-facing API for bus ETA, occupancy levels, and AQI at nearest bus stop. Backed by PostGIS spatial queries and InfluxDB. CDN-cached for 15-s freshness.
GET /api/v1/buses/nearby?lat=&lon= GET /api/v1/route/{route_id}/eta GET /api/v1/stops/{stop_id}/aqi
🔌
Grid & Utility API
Utility planners · Demand-response systems
Exposes ward-level energy demand forecasts and live anomaly alerts. Used by utility operators to pre-position grid reserves and trigger demand-response programmes.
GET /api/v1/energy/forecast/{ward_id} GET /api/v1/energy/anomalies/active WS /ws/meter-alerts
